# Metodología pública del proyecto GBG

Este sitio es la **capa pública, interactiva y versionada** de la metodología institucional para vigilancia, análisis espacial, percepción remota y modelación del gusano barrenador del ganado (*Cochliomyia hominivorax*) en Escárcega y Champotón, Campeche.

!!! info "Fuente científica"
    La metodología científica se mantiene y modifica únicamente en el repositorio privado de trabajo. Este repositorio público recibe **exportaciones controladas y sanitizadas**; no es una segunda fuente de verdad.

## Qué aporta esta versión web

- ecuaciones renderizadas con MathJax;
- tablas y bloques metodológicos con mejor legibilidad;
- navegación por secciones;
- citas con **trazabilidad interactiva de evidencia**;
- distinción explícita entre lo que una fuente **sustenta**, cómo se **aplica** y lo que **no sustenta**;
- acceso a fichas de evidencia pública sin exponer matrices, PDFs, datos sensibles ni materiales internos;
- versionado de cada liberación pública.

## Regla de publicación

El flujo es unidireccional:

**repositorio privado → validación/sanitización → GusanoBG-P → GitHub Pages**

Nunca se editará la metodología científica directamente en este repositorio público.
