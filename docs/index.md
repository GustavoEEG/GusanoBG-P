# Metodología pública del proyecto GBG

Este sitio es la **capa pública, interactiva y versionada** de la metodología institucional para la caracterización ecológica, distribución, dispersión y riesgo del gusano barrenador del ganado (*Cochliomyia hominivorax*) en Escárcega y Champotón, Campeche.

!!! info "Fuente científica vigente"
    La fuente canónica es `metodologia/00_metodologia_principal_corregida.md`, mantenida y modificada únicamente en el repositorio privado de trabajo. Este repositorio público recibe **exportaciones controladas y sanitizadas**; no es una segunda fuente de verdad.

## Qué aporta esta versión web

- ecuaciones renderizadas con MathJax;
- tablas y bloques metodológicos con mejor legibilidad;
- navegación por secciones;
- citas con **trazabilidad interactiva de evidencia por instancia**;
- distinción explícita entre **Sustenta**, **Aplicación en GBG**, **No sustenta** y **Prueba documental**;
- acceso a fichas de evidencia pública sin exponer matrices, PDFs, datos sensibles ni materiales internos;
- versionado de cada liberación pública.

## Regla de publicación

El flujo es unidireccional:

**`00_metodologia_principal_corregida.md` privado → inventario y prueba documental completa → validación/sanitización → PR en GusanoBG-P → GitHub Pages**

La publicación se bloquea mientras falte una sola aparición autor–año del cuerpo metodológico o mientras alguna ficha corresponda a la metodología anterior. Nunca se editará la metodología científica directamente en este repositorio público.
